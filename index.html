01 · MESMO PROBLEMA DO TP-II

Minimizar cores, respeitando as arestas.

Modelo inteiro

x[v,c] = 1 quando v recebe c; y[c] = 1 quando c é utilizada.

min Σc y[c]
  • Σc x[v,c] = 1, para todo vértice.
  • x[u,c] + x[v,c] ≤ y[c], para toda aresta.
  • x[v,c] ≤ y[c], inclusive para vértices isolados.
  • x e y binários; cores y ordenadas para reduzir simetria.

DSATUR limita a paleta; uma clique gulosa fornece um limite inferior válido.

Gerador G(N,p)

Cada par de vértices recebe uma aresta independentemente, com probabilidade 0,5.

N = 10, 15, 20, 30, 40, 60 vértices.

seed = 2026 + 1000 × réplica + N

Três grafos diferentes por tamanho. As arestas completas e os arquivos DIMACS estão em data/.

Os tamanhos menores cobrem casos fáceis; os maiores investigam a dificuldade de provar o ótimo.

02 · COMPARAÇÃO

Quatro abordagens. Um orçamento.

Busca Tabu pura

DSATUR inicial → tentativa com k−1 cores → movimentos de recoloração que reduzem conflitos. Memória tabu, aspiração e reinícios.

Somente colorações válidas entram no resultado.

Exato puro

HiGHS resolve o modelo completo. DSATUR fornece apenas o tamanho da paleta; nenhuma coloração é injetada como MIP start.

Exato + warm start

Tabu por até 10% de T. O vetor x/y da coloração válida é enviado ao HiGHS. Modelo completo no tempo restante.

Híbrido completo

Tabu (até 10%) → Fix-and-Optimize (até 40%) → MIP completo no restante. Cada subproblema recebe até 2 segundos.

Preparação, warm start e F&O entram no tempo total. As fases podem terminar cedo. Não há tempo extra para o híbrido.

03 · DECISÃO DE PROJETO

Fixar a maior parte. Reconsiderar o que importa.

Quais vértices ficam livres?

  1. Todos os vértices da menor classe de cor.
  2. Prioridade aos seus vizinhos.
  3. Maior saturação e maior grau para completar a janela.

A menor classe é renomeada para a última cor, permitindo desligá-la com as cores y ordenadas.

Os demais vértices mantêm suas cores. O solver tenta reduzir o número total de cores nesse subproblema.

Janela adaptativa e ablação

K inicial ≈ 40% de N, com mínimo 5. Se resolver em menos de 1 s, aumenta 25%; se não resolver, reduz 30%.

Interrompe após quatro tentativas sem melhoria ou ao esgotar a fase.

Ablação: críticos × aleatório × misto. Todas liberam a menor classe; muda a seleção dos vértices adicionais.

Ótimo de uma vizinhança não prova o ótimo do grafo completo. Só o MIP global produz essa coluna de certificado.

04 · RESULTADOS REAIS

Até onde o solver consegue provar?

Certificado do HiGHS no modelo completo; T inclui todas as fases. Percentuais são calculados sobre três réplicas.

05 · SOLUÇÃO E CERTIFICADO

Encontrar uma coloração e provar o ótimo.

Gap de certificado

100 × (cores − LB de referência) / cores. Usa limites globais válidos; limites de F&O são excluídos.

Excesso primal

100 × (cores − melhor observado) / melhor observado. Zero significa igualar o melhor valor observado, sem garantir ótimo.

LB ≤ χ(G) ≤ UB · menor número de cores é melhor

08 · INTERPRETAÇÃO

A vantagem depende da instância e da fase.

Como interpretar

  • Warm start ajuda a obter um incumbente; a prova depende também do limite inferior e da simetria do modelo.
  • F&O busca reduzir cores em vizinhanças. Fixações podem impedir uma melhoria que exige mudanças globais.
  • Compare o híbrido com warm start sozinho para avaliar o custo adicional do F&O.
  • A ablação testa se a seleção dos vértices críticos traz vantagem observável.

Limites do estudo

  • Três grafos por tamanho; um gerador G(N,p).
  • HiGHS , uma thread, T comum.
  • Ótimo observado ≠ ótimo provado.
  • O limite de tamanho encontrado vale para este conjunto e orçamento.
  • Pequenos excessos de tempo do solver estão registrados, com preparação incluída.

REPRODUÇÃO E VERIFICAÇÃO

Um experimento auditável.

Procedimento

  1. Gerar 18 grafos com parâmetros e seed documentados.
  2. Rodar cada abordagem independentemente e em sequência.
  3. Validar todas as colorações pelas arestas do grafo.
  4. Salvar colorações, limites globais, tempo, traces e fixações.
  5. Gerar gráficos e conclusões diretamente desses dados.

DSATUR e clique são pré-processamentos comuns no MIP. A heurística pode parar cedo quando atinge o limite da clique; a coluna de prova permanece exclusiva do solver global.

Como reproduzir

python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python run_experiments.py --T 20 --reps 3
python validate_results.py
python analyze.py

Depois, abra index.html. Não precisa de internet ou servidor para a apresentação.

Seeds reproduzem os grafos; resultados com limite de relógio podem variar com a máquina.

Referência compartilhada só na análise

LB de referência = maior teto seguro dos limites inferiores globais observados na mesma instância. Melhor observado = menor quantidade de cores entre todas as execuções. Esses valores não são entregues aos algoritmos durante os experimentos.
